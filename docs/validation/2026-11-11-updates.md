## Migration prerequisites

- [Jellyfin 12 upgrade guidance](https://jellyfin.org/posts/jellyfin-release-12.0/)
  requires a stopped data/config backup, checking case-insensitive usernames,
  reviewing plugins, and a full library scan. The live database has two users,
  no case-insensitive username collisions, and no plugin DLLs in its data plugin
  directory. Hardware transcoding and client playback must be rechecked after
  migration.
- [MariaDB 11.4 to 11.8](https://mariadb.com/docs/server/server-management/install-and-upgrade-mariadb/upgrading/mariadb-community-server-upgrade-paths/upgrading-from-mariadb-11-4-to-mariadb-11-8)
  is an LTS upgrade. Stop BookStack while upgrading its database and run
  `mariadb-upgrade` before reopening the application. The LinuxServer image
  documents this [upgrade procedure](https://docs.linuxserver.io/images/docker-mariadb/#upgrading).
- [Homebridge 2 guidance](https://github.com/homebridge/homebridge/wiki/Updating-To-Homebridge-v2.0)
  requires supported Node and compatible plugins. Registry metadata confirms
  the installed Govee 11.39.1 and OpenRGB 1.5.0 are current; their declared engine
  ranges allow Homebridge 2.5.0 and Node 26. Both plugins loaded successfully.
